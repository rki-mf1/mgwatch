How to Get Started

Welcome to MetagenomeWatch. To get started, simply upload a FASTA file with your favourite genomic sequence. The search will run in the background and you will be sent to a result page that updates while the search is running. You can bookmark that page, leave it open until the results appear, or start another search in a new tab.
